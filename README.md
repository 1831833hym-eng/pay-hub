# 付款中心

独立前端应用（非 Fund 子模块）。视觉参考企业后台列表页风格：左侧菜单、顶栏面包屑/Tab、查询面板 + 数据表格。

## 业务说明

承接飞书审批的付款申请信息，生成付款单；提交复核通过后，通过万里汇付款接口出款；付款完成后获取万里汇回单，并上传至飞书审批流。

## 菜单（左侧）

1. **提交付款单** `/submit`
2. **复核付款单** `/review`（只读，不可编辑）
3. **查询付款单** `/query`（全量查询，只读查看）

## 查询条件

付款单编号、飞书审批编号、付款申请类型、付款事由、付款金额、收款方式类型  
按钮：【搜索】【重置】

## 列表字段

付款单编号、飞书审批编号、付款申请类型、付款事由、付款金额、收款方式类型、币种、申请人、申请时间、付款单状态、创建时间、更新时间

## 明细字段

付款单编号、飞书审批编号、付款申请类型、付款事由、付款金额、币种、申请人、申请时间、付款单状态、收款方式类型、收款人账户类型、收款账号、收款银行、转账附言（默认飞书审批编号）

## 状态流转

待提交 →（提交）→ 待复核 →（复核通过）→ 待付款 →（万里汇付款成功）→ 待回单 →（获取回单并回传飞书）→ 已完成

## 本地运行

```bash
npm install
npm run dev -- -p 43123
```

打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)
