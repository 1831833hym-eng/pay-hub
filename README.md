# 付款中心

独立前端应用（非 Fund 子模块）。视觉参考企业后台列表页风格：左侧菜单、顶栏面包屑/Tab、查询面板 + 数据表格。

## 业务说明

承接飞书审批的付款申请信息，生成付款单；提交复核通过后，通过万里汇付款接口出款；付款完成后获取万里汇回单，并上传至飞书审批流。

## 菜单（左侧）

1. **提交付款单** `/submit`（仅待提交）
2. **复核付款单** `/review`（仅待复核；明细只读；可选择付款渠道，默认万里汇；支持确认/退回）
3. **查询付款单** `/query`（全部状态，只读查看）

复核退回后状态变为待提交，单据回到「提交付款单」列表。

## 查询条件

付款单编号、飞书审批编号、付款申请类型、付款金额、付款事由、收款方式类型  

按钮：【搜索】【重置】

## 列表字段

付款单编号、飞书审批编号、审批流程名称、付款申请类型、付款金额、付款事由、币种、收款方式类型、申请人、申请时间、付款单状态、创建时间、更新时间

## 明细字段

付款单编号、飞书审批编号、审批流程名称、付款申请类型、付款事由、付款金额、币种、申请人、申请时间、付款单状态、收款方式类型、收款人账户类型、收款账号、收款银行、转账附言（默认飞书审批编号）

## 状态流转

待提交 →（提交）→ 待复核 →（确认）→ 待付款 →（万里汇付款成功）→ 待回单 →（获取回单并回传飞书）→ 已完成  
待复核 →（退回）→ 待提交

## 本地运行

```bash
npm install
npm run dev -- -p 43123
```

打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)

## GitHub Pages

本仓库已配置静态导出（`output: "export"`）与 Actions 部署工作流（`.github/workflows/deploy-pages.yml`）。

1. 将代码推送到 GitHub 仓库的 `main` 分支  
2. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**  
3. 推送后自动构建并发布；站点地址一般为 `https://<用户名>.github.io/<仓库名>/`
