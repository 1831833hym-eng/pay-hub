# 付款中心 · 资金中台原型

跨境电商资金中台的**付款中心**交互原型。视觉风格对齐「资金中台管理系统」（蓝紫渐变、白卡片、顶栏导航）。

## 业务链路

1. **承接飞书审批**：审批通过后拉取付款申请信息  
2. **生成付款单**：映射金额、收款方、用途等字段  
3. **提交复核**：财务复核通过后方可出款  
4. **万里汇付款**：调用万里汇付款接口出款  
5. **回单回传飞书**：获取万里汇回单并上传至原飞书审批流  

## 页面

| 路径 | 说明 |
|------|------|
| `/` | 付款中心概览与端到端链路 |
| `/feishu` | 飞书审批承接 / 生成付款单 |
| `/payments` | 付款单列表 |
| `/payments/[id]` | 付款详情与流程轨迹 |
| `/review` | 复核中心 |
| `/worldfirst` | 万里汇出款队列 |
| `/receipts` | 回单获取与回传飞书 |

数据为前端 Mock，无真实飞书/万里汇对接。

## 本地运行

```bash
npm install
npm run dev -- -p 43123
```

打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。
