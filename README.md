# 付款中心 · 资金中台原型

视觉风格对齐「资金中台管理系统」（蓝紫渐变、白卡片、顶栏导航）。

## 业务说明

承接飞书审批的付款申请信息，生成付款单；提交复核通过后，通过万里汇付款接口出款；付款完成后获取万里汇回单，并上传至飞书审批流。

## 菜单（两个）

1. **提交付款单** `/submit`
2. **复核付款单** `/review`（只读，不可编辑）

## 查询条件

付款单编号、飞书审批编号、付款申请类型、付款事由、付款金额  
按钮：【搜索】【重置】

## 列表字段

付款单编号、飞书审批编号、付款申请类型、付款事由、付款金额、币种、申请人、申请时间、付款单状态、创建时间、更新时间  

提交页额外按钮：【批量提交】【编辑】【查看】  
复核页仅：【查看】

## 明细字段

付款单编号、飞书审批编号、付款申请类型、付款事由、付款金额、币种、申请人、申请时间、付款单状态

## 状态流转

待提交 →（提交）→ 待复核 →（复核通过）→ 待付款 →（万里汇付款成功）→ 待回单 →（获取回单并回传飞书）→ 已完成

## 本地运行

```bash
npm install
npm run dev -- -p 43123
```

打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)
