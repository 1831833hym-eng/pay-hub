## 业务说明

承接飞书审批的付款申请信息，生成付款单；提交复核通过后，通过万里汇付款接口出款；付款完成后获取万里汇回单，并上传至飞书审批流。

## 菜单（左侧）

1. **初审付款单** `/submit`（仅待初审；支持初审、批量初审、作废）
2. **复核付款单** `/review`（仅待复核；明细只读；付款渠道只读不可编辑，未写入时展示万里汇，确认时系统写入；支持复核确认/退回）
3. **查询付款单** `/query`（全部状态，含已作废；操作列有作废、重新支付、查看。点击重新支付后提示「已成功提交支付，请稍等。」）
4. **查询比对结果** `/compare`（付款单与审批单对照：编号、金额、币种、收款人、收款账号；比对结果为一致/不一致；不含已作废付款单）

复核退回后状态变为待初审，单据回到「初审付款单」列表。

## 查询条件

付款单号、审批单号、付款申请类型、付款金额、付款事由、收款方式类型  


按钮：【搜索】【重置】

## 列表字段

付款单号、审批单号、审批单名称、付款申请类型、付款金额、付款事由、币种、收款方式类型、申请人、申请时间、付款单状态、创建时间、更新时间

查询引导页在付款单状态右侧另有：支付状态、支付失败原因。

## 明细字段

付款单号、审批单号、审批单名称、付款申请类型、付款事由、费用具体明细、付款金额、币种、申请人、申请时间、付款单状态、收款方式类型、转账附言、收款人账户类型、收款账号、收款银行、银行所在地区、银行支行、收款人身份证号码、收款人邮箱号码、收款人手机号码  

初审/复核可填写本次处理意见。明细页底部「处理历史」面板展示已办环节与处理意见。查询明细在处理历史前展示回单信息（付款流水号、回单时间、付款回单附件）。

## 状态流转

待初审 →（初审）→ 待复核 →（复核确认）→ 待支付 →（万里汇付款成功）→ 待回单 →（获取回单并回传飞书）→ 已完成  
待复核 →（退回）→ 待初审  
待初审 →（作废）→ 已作废（逻辑删除：只改状态，不删除单据；初审列表不再展示，查询可查看）

## 本地运行

```bash
npm install
npm run dev -- -p 43123
```

打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)

## GitHub Pages

本仓库已配置静态导出（`output: "export"`）与 Actions 部署工作流（`.github/workflows/deploy-pages.yml`）。

1. 将代码推送到 GitHub 仓库的 `main` 分支  
2. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**  
3. 推送后自动构建并发布；站点地址一般为 `https://<用户名>.github.io/<仓库名>/`
