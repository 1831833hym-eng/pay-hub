# 付款中心 · 资金中台原型

跨境电商资金中台的**付款中心**交互原型，视觉风格对齐现有「资金中台管理系统」（蓝紫渐变背景、白卡片、顶栏导航）。

## 功能范围

- **付款中心首页**：今日付款额、待审核、付款中、成功率；快捷入口；最近付款单；通道健康度
- **付款单列表**：按单号 / 商户 / 收款方、状态、币种筛选
- **发起付款**：单笔表单（账户、收款方、金额、用途、通道与费用预估）+ 批量导入示意
- **付款详情**：金额摘要、基本信息、审核/出款流程轨迹、审核操作区
- **收款方管理**：供应商 / 物流商 / 服务商账户与认证状态

数据为前端 Mock，便于产品评审与走查，无后端依赖。

## 本地运行

```bash
npm install
npm run dev -- -p 43123
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

## 技术栈

Next.js (App Router) · TypeScript · Tailwind CSS · Lucide Icons
