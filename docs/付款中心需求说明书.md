## 2. 需求说明

### 2.1 背景

跨境付款申请在飞书审批中完成，但出款、复核、回单回传缺少统一工作台。需要独立「付款中心」承接已通过的审批信息，生成付款单，完成初审、复核、出款与回单，并支持查询与单据比对。

### 2.2 目标

| 编号 | 目标 | 衡量标准 |
| --- | --- | --- |
| G1 | 统一承接审批单并生成付款单 | 付款单含审批单编号、名称、金额、收款信息 |
| G2 | 分环节处理 | 初审、复核、查询、比对四个菜单，数据范围互不串单 |
| G3 | 出款后闭环 | 复核通过进入待付款；付款成功后待回单；回单回传后已完成 |
| G4 | 作废可追溯 | 作废为逻辑删除，查询可看，初审列表不可见 |

### 2.3 范围

| 类型 | 说明 |
| --- | --- |
| 范围内 | 初审 / 复核 / 查询 / 比对四个菜单；列表查询、分页、合计；明细基础信息、收款账户、处理历史；初审、作废、复核确认 / 退回 |
| 范围外 | 真实飞书 / 万里汇联调、登录鉴权、账务核销、打印回单实体文件、权限中心 |

### 2.4 干系人与角色

| 角色 | 职责 | 主要操作 |
| --- | --- | --- |
| 初审岗 | 核对付款单并提交复核 | 查询、初审、单笔作废、重新同步 |
| 复核岗 | 确认出款或退回 | 选择付款渠道、确认、退回 |
| 查询岗 | 只读查看全部单据 | 按条件与状态查询、看明细 |
| 对账岗 | 核对付款单与审批单 | 查询比对结果 |

### 2.5 术语

| 术语 | 定义 |
| --- | --- |
| 付款单 | 承接审批信息后在付款中心生成的出款单据 |
| 审批单 | 飞书审批流单据，编号默认写入转账附言 |
| 初审 | 待初审单据提交至待复核的动作 |
| 作废 | 将待初审单据状态改为已作废，不物理删除 |
| 比对结果 | 付款单与审批单在金额、币种、收款人、收款账号上的一致 / 不一致 |

### 2.6 假设、依赖与约束

| 类型 | 说明 |
| --- | --- |
| 假设 | 进入付款中心的审批单已审批通过 |
| 依赖 | 飞书审批、万里汇付款与回单（本期为原型模拟） |
| 约束 | 作废不可物理删除；比对列表排除已作废；复核付款渠道必填，默认万里汇 |

## 4. 实体设计

### 4.1 实体关系

一张付款单对应一张审批单。付款单拥有多条处理历史。出款交易号、回单号挂在付款单上。比对结果由付款单与审批单字段实时对照，不单独落库。

```text
审批单 1 ── 1 付款单
付款单 1 ── N 处理历史
付款单 1 ── 0..1 出款回单（万里汇交易号 / 回单号）
付款单 × 审批单 ──> 比对结果（计算）
```

### 4.2 实体清单

| 实体 | 说明 | 主键 | 生命周期 |
| --- | --- | --- | --- |
| 付款单 | 出款主单据 | id | 生成 → 初审 → 复核 → 出款 → 回单 → 完成；或作废 |
| 处理历史 | 环节处理意见 | 付款单 id + 时间 | 随操作追加，不删改 |
| 比对结果 | 展示用对照行 | 付款单 id | 查询时计算 |

## 5. 业务流程

### 5.1 主流程

```text
1. 飞书审批通过 → 系统生成付款单，状态 = 待初审
2. 初审岗在「初审付款单」核对，填写意见，点击【初审】→ 待复核
3. 复核岗选择付款渠道（默认万里汇），【确认】→ 待付款
4. 调用万里汇出款成功 → 待回单（记录交易号）
5. 获取回单并回传飞书 → 已完成（记录回单号）
```

### 5.2 流程节点

| 步骤 | 角色 | 动作 | 系统处理 | 结果状态 |
| --- | --- | --- | --- | --- |
| 1 | 系统 | 承接审批 | 生成付款单 | 待初审 |
| 2 | 初审岗 | 初审 | 写处理历史「初审」 | 待复核 |
| 3 | 复核岗 | 确认 | 记录付款渠道；写「复核」 | 待付款 |
| 4 | 系统 | 出款成功 | 记交易号 | 待回单 |
| 5 | 系统 | 回单回传 | 记回单号 | 已完成 |

### 5.3 分支与异常流程

| 场景 | 触发 | 处理 | 结果 |
| --- | --- | --- | --- |
| 复核退回 | 复核岗【退回】 | 状态改待初审；历史记复核退回 | 回到初审列表 |
| 作废 | 初审行内【作废】并确认 | 状态改已作废，不删数据 | 初审列表消失，查询仍可见 |
| 比对不一致 | 金额 / 币种 / 收款人 / 账号不同 | 结果列「不一致」，差异格标红 | 仍可查询，不改状态 |

### 5.4 协作系统

| 系统 | 方向 | 时机 | 数据 | 失败策略 |
| --- | --- | --- | --- | --- |
| 飞书 | 进 | 审批通过 | 审批单号、名称、金额、收款信息 | 本期手工 / 模拟接入 |
| 飞书 | 出 | 回单完成 | 回单号 | 本期模拟 |
| 万里汇 | 出 | 复核确认后出款 | 金额、账号、附言、渠道 | 本期模拟；可「重新同步」 |
